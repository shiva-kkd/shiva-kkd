## 🚀 Featured Projects

### 1. Real-Time Energy Consumption Monitoring and Prediction System

An AI-powered energy monitoring and prediction platform designed to analyze electricity consumption, detect unusual usage, and support energy optimization.

- Developed a real-time energy monitoring dashboard.
- Implemented Random Forest and XGBoost prediction models.
- Used Isolation Forest for anomaly detection.
- Integrated Particle Swarm Optimization (PSO) for energy optimization.
- Achieved 5.98% MAPE with Random Forest and 5.88% MAPE with XGBoost.

**Technologies:** React.js, Express.js, Python, FastAPI, Scikit-learn, Random Forest, XGBoost.

### 2. Image Steganography Using LSB Technique

A web-based application that hides secret messages inside images using the Least Significant Bit (LSB) steganography technique.

- Encode secret messages into images.
- Decode hidden messages from encoded images.
- Upload and download images through a web interface.
- Implemented image processing using OpenCV and NumPy.

**Technologies:** Python, Flask, OpenCV, NumPy, HTML, CSS.

### 3. Skill Exchange Platform

A platform that allows users to exchange skills and services without requiring direct monetary payments.

- User registration and authentication.
- Skill listing and discovery.
- Connect users based on their skills.
- Developed using a full-stack web architecture.

**Technologies:** React.js, MongoDB, JavaScript.

### 4. AWS Cloud Computing Static Website

A cloud-based static website deployment project using Amazon Web Services.

- Hosted a static website using AWS.
- Explored cloud infrastructure and deployment.
- Used GitHub for version control.

**Technologies:** AWS EC2, AWS S3, HTML, CSS, GitHub.
